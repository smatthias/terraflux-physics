# Weather map examples

The first fixture should be a small radar reflectivity map with a known palette, valid time, and georeferencing. Record its source, product type, scan/elevation context when available, legend interpretation, and expected dBZ observations. Include a no-data color and at least one ambiguous color case.

Do not infer rainfall accumulation from reflectivity in this fixture. Keep source-use restrictions and any sidecar metadata documented.

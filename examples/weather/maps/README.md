# Weather map examples

The first fixture should be a small synthetic radar reflectivity map that mirrors the input structure of the BOM Melbourne (Broadmeadows) 256 km product candidate (IDR012) without containing BOM imagery. Record its source as synthetic, product type, UTC valid time, raster dimensions, palette/legend interpretation, coordinate transform or control points, expected dBZ observations, no-data color, and at least one ambiguous color case.

Do not infer rainfall accumulation from reflectivity in this fixture. Do not commit live BOM radar images until applicable source-use terms are cleared. Keep fixture generation steps and sidecar metadata documented.
